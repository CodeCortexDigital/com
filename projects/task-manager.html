A modern task management solution for organizing work, tracking progress, and managing deadlines — with secure JWT auth, full CRUD, a drag-and-drop Kanban board, and a real-time analytics dashboard, deployed on Vercel + Render.

Main Features

Everything you need to plan, track, and ship tasks — on any device.
